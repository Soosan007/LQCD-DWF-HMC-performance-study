# 研究概要

## 背景

格子QCDのDWF-HMC計算では、フェルミオン行列を含む線形方程式の反復解法が多数回呼び出されます。富岳向けACLE実装は下層のWilson演算を高速化しますが、局所カーネルの高速化がCG全体やHMC全体にどの程度反映されるかは、呼出回数、反復回数、メモリ転送、その他の処理割合に依存します。

## 目的

1. GenoaでMPI/OpenMP構成によるDWF-HMC全体時間の変化を確認する。
2. 富岳でACLE版とGENERAL版の内部処理時間を把握する。
3. CGとDdagDのメモリ帯域律速部分を融合し、局所処理、ソルバー全体、HMC全体への影響を分けて評価する。
4. 反復回数、最終残差、`H(diff)` を確認し、性能差が数値結果の変化によるものではないことを確かめる。

## 評価した変更

- CGプロファイリング
- DdagD詳細プロファイリング
- 前回解再利用
- `axpy + norm2` 融合
- `copy + axpy` 融合
- 公平なsingle-outer-block計測

## 結論の範囲

融合対象の局所区間では明確な短縮を確認しました。CG全体への反映は小さく、HMC全体では測定変動が支配的でした。そのため、この研究では局所処理の短縮と全体性能の差を分けて報告します。
